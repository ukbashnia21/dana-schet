# Устный счёт — тренажёр для Даны

Одна страница без сервера и без внешних зависимостей (шрифты подтягиваются с Google Fonts, без сети — системные).
Прогресс хранится в браузере на компьютере Даны (localStorage).

## Выложить на GitHub Pages
```bash
cd dana-schet
git init && git add . && git commit -m "Устный счёт v3"
gh repo create dana-schet --public --source=. --push
gh api -X POST repos/{owner}/dana-schet/pages -f "source[branch]=main" -f "source[path]=/"
```
Через минуту сайт будет на `https://<логин>.github.io/dana-schet/`.

## Установить у Даны как приложение
- Chrome / Edge: открыть ссылку → значок «Установить» в адресной строке → появится в Пуске / Dock, открывается отдельным окном, работает без интернета.
- Safari на Mac: Файл → «Добавить в Dock».

## Обновление
Меняете index.html → `git commit -am "..." && git push`. У Даны новая версия подтянется при следующем запуске (номер версии внизу экрана).
При заметных изменениях поднимите `C='ustny-v3'` в sw.js.

## Статистика
Родителям → «Скопировать резервную копию» → вставить текст в чат с Claude для разбора. Там же «Восстановить».
